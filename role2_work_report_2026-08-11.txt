四、其他成员使用时的注意事项

1. 现有调用方可以继续只使用 worker_ledger 和 events，不要求立即适配 execution_ledger。

2. execution_ledger 是 append-only 历史，不应按 agent 名称覆盖记录。若只需要当前状态，继续使用 worker_ledger。

3. execution_type 必须如实填写。确定性 adapter、reviewed pipeline 和 external port 不能标成 opencode_subagent。

4. ledger 只允许放公开引用，不得写入 API key、Token、Authorization、隐藏测试、参考答案、secure artifact 内容或本机私有绝对路径。

5. collaboration_metrics 来自公开 ledger 的运行协同事实，不等同于角色4负责的学习效果、难度适配率、幻觉率或最终竞赛指标。

6. 本次没有修改角色1的业务状态机决策，没有修改角色3的审核/修复/降级规则，也没有修改角色4的整体 UX。
